# TAPD 坐标复制脚本

这是一个 Tampermonkey/油猴脚本。安装 `tapd-coordinate-copy.user.js` 后，在支持的 TAPD 缺陷页面找到坐标时，右下角会显示汇总窗口。

支持以下页面：

- 缺陷详情页：`/tapd_fe/<项目ID>/bug/detail/<缺陷ID>`。
- 缺陷列表的侧面预览：`/tapd_fe/<项目ID>/bug/list?...&dialog_preview_id=bug_...`。
- 查询过滤的侧面预览：`/tapd_fe/worktable/search?...&dialog_preview_id=bug_...`。

侧面预览只扫描当前可见的缺陷抽屉，不汇总背景列表。列表页和查询过滤页未打开缺陷预览时，不显示汇总窗口。

- 自动扫描标题和详细内容中的 `(X=...,Y=...,Z=...)` 坐标。
- 兼容中文括号 `（）`、中文逗号 `，`、缺逗号写法，以及某个坐标值为空或缺失的格式（如 `（X=1，Y=，Z=3）`、`（X=1，Z=3）`）。
- 页面未命中任何坐标时，不显示汇总窗口。
- 坐标原文只显示坐标本身，X/Y/Z 复制按钮水平排列。
- 点击 `X`、`Y` 或 `Z` 数值会直接复制该数字。
- 点击坐标行（非 X/Y/Z 复制按钮区域）会平滑滚动定位到页面上对应坐标所在位置，并高亮闪烁提示。
- 汇总窗口固定在页面右下角。
- 关闭按钮位于汇总窗口右下角。
